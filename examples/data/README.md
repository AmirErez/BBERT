# BBERT Example Data

This directory contains example data files for testing and demonstrating BBERT functionality.

## Quick Start Test Files

### Minimal Test File
- **`example.fasta`** (4KB) - Tiny test file for quick validation
  ```bash
  bbert infer examples/data/example.fasta --output-dir results
  ```

### Realistic Test Data (Recommended)
Paired-end sequencing reads from bacterial and eukaryotic organisms:

**Bacterial (Pseudomonas aeruginosa)**
- `Pseudomonas_aeruginosa_R1.fasta.gz` (328KB)
- `Pseudomonas_aeruginosa_R2.fasta.gz` (328KB)

**Eukaryotic (Saccharomyces paradoxus)**
- `Saccharomyces_paradoxus_R1.fasta.gz` (336KB)
- `Saccharomyces_paradoxus_R2.fasta.gz` (340KB)

```bash
# Process all paired-end reads
bbert infer examples/data/*.fasta.gz --output-dir results
```

- **S. cerevisiae** (GCF_000146045)

### Usage
The script automatically handles both compressed (.gz) and uncompressed files:
```bash
python scripts/testing/generate_annotated_reads.py \
  --genome examples/data/GCF_000005845_E_coli.fasta.gz \
  --gtf examples/data/GCF_000005845_E_coli.gtf.gz \
  --output-dir synthetic_reads/
```

## Generated Files (Not Included in Package)

The following files are **generated outputs** and are excluded from the package. Users will create these by running BBERT:

- `*.parquet` - Score files generated by `bbert infer` or `examples/utilities/score.py`
- `*_scores_len.parquet` - Sequence scores with lengths
- `*_scores_len_emb.parquet` - Scores with embeddings (using `--emb-out`)

### Generate Example Outputs
```bash
# Generate score files
bbert infer examples/data/example.fasta --output-dir results

# With embeddings
bbert infer examples/data/Pseudomonas_aeruginosa_R1.fasta.gz \
  --output-dir results --emb-out --max-reads 1000
```

## Data Sources

- Reference genomes: NCBI RefSeq
- Test reads: Simulated from reference genomes
- Visualizations: Generated using t-SNE on BBERT embeddings

## Notes

- All reference genomes are compressed with gzip (`.gz` extension)
- Python's `gzip` module can read compressed files directly
- Most BBERT scripts handle `.gz` files automatically
